# مصروفي

تطبيق ويب تقدمي بواجهات عربية وإنجليزية وتركية لإدارة الدخل والمصروفات والميزانيات والتقارير والمعاملات المتكررة. يمكن تبديل اللغة من الشريط العلوي؛ تحفظ اللغة المختارة وتُضبط صيغة التاريخ والعملة واتجاه الواجهة تلقائيًا.

## الخصوصية والتخزين

يحفظ التطبيق كل سجله وإعدادات اللغة في مساحة `localStorage` داخل المتصفح على الجهاز نفسه. لا يوجد تسجيل دخول أو ربط مصرفي أو واجهة خادم أو مزامنة/نسخة احتياطية سحابية في هذه النسخة. حذف بيانات المتصفح قد يحذف السجل أيضًا؛ يمكن تثبيت التطبيق على الجهاز من قائمة المتصفح.

## التطوير

- `pnpm install`
- `pnpm dev`
- `pnpm build`
